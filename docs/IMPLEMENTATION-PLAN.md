# 연구실 홈페이지 개편 구현 계획

기준일: 2026-10-16. 원본: hongjo/hongjo.github.io, ade15b27f34fddc9aa74469a745ac48f4c8bc2fc. 디자인: 프로젝트에 제공된 HTML5 UP Story. 논문 탐색 참고: SH-Joo/SH-joo.github.io의 design-draft.html.

## 완료 기준

- 기존 52개 한영 페이지와 원래 주소를 유지한다. 연구실 데이터와 블로그 본문은 원문 그대로 보존한다.
- 교수 1명과 구성원 35명, 연구실적 128건(저널 42, 국제학회 37, 국내학회 29, 특허 20), 과제 18건, 12학기 26개 강의, 언어별 블로그 15편, 앨범 18개와 사진 76장을 보존한다.
- 논문 검색, 연도 및 유형 선택, 보조 연구주제 필터, 검색 결과 수·빈 결과·초기화를 제공한다. Selected 버튼, 선정 별표, 선정 논문 전용 목록은 만들지 않는다. 기존 홈의 대표 연구 소개는 보존한다.
- 구성원별 실적 자동 연결, 교수 상세 소개, 블로그 계층형 목차와 다음 글, 원본 이미지 확대, 한영 대응, 구형 해시 주소를 보존한다.
- 포크의 경로 접두사와 운영 사이트의 루트 경로 모두에서 링크·이미지·메타데이터가 작동한다.
- 360/390/768/1440px에서 본문 잘림과 페이지 가로 넘침이 없어야 한다. 긴 표만 영역 안에서 가로 스크롤을 허용한다.
- 키보드 탐색, 명확한 포커스, 메뉴 상태, 모달 닫기와 포커스 복귀, 적절한 제목 계층, 모션 감소 설정을 지원한다.
- 검증에서 치명적 결함(P0)과 주요 결함(P1)이 남아 있으면 완료로 판정하지 않는다. 화면·콘텐츠·동작의 결과와 남은 제한을 기록한다.

## 1단계 원본과 포크

원본 커밋과 전체 이미지·데이터를 확보한다. upstream은 교수님 저장소, origin은 개인 계정의 포크로 설정하고 redesign/story 브랜치에서 작업한다. 교수님 저장소로 직접 푸시하지 않는다. 원본 콘텐츠의 해시와 페이지 목록을 비교 기준으로 저장한다. 분석용 .reference와 템플릿 ZIP은 배포와 Git 추적에서 제외한다.

## 2단계 공통 디자인

Story의 banner, spotlight, wrapper, items, gallery를 실제 페이지 구성의 기반으로 사용한다. 색은 흰색·따뜻한 회색·연세 네이비·절제된 청록으로 정한다. 본문은 얇은 300 굵기를 피하고 기본 16–18px, 행간 1.7 이상으로 한다. 긴 읽기 본문은 약 70자 폭으로 제한한다. 한글은 keep-all과 overflow-wrap을 함께 적용한다.

헤더는 연구실 이름, 핵심 메뉴, 한영 전환을 제공한다. 메뉴가 두 줄로 압축되기 전 모바일 메뉴로 전환한다. 푸터에는 원래 주소·메일·전화와 연구실 소개·지원·디자인 출처를 제공한다. 현재 메뉴, 링크, 버튼은 색상 외에 밑줄·테두리·텍스트로 구분한다.

컴포넌트 CSS는 Story CSS 위에 범위를 명확히 두어 적용한다. 연구 도식은 contain, 인물사진은 얼굴이 잘리지 않는 비율, 앨범은 전체 사진과 캡션을 기본으로 한다. 첫 화면의 대표 사진은 빠르게 로드하고 나머지 이미지는 반응형 WebP와 지연 로딩을 유지한다.

## 3단계 홈과 소개

홈은 원래 히어로 문구와 사용자가 제공한 인프라 대표 이미지 → 연구 접근 방법 → 비전 → 대표 연구 → 연구분야 → 소식 → 블로그 → 연구실 단체사진 → 인재상 → 연락처로 이어진다. 원본의 Observe/Understand/Act 설명도 보존한다. 새 홍보 문구나 연구 성과는 만들지 않는다. 긴 원문 소개와 전체 뉴스, 교수 소개는 기존 about/news/faculty 주소로 제공한다.

추가된 사용자 이미지 8장의 배치는 image_prompts.txt를 따른다. 1번은 히어로, 2번은 소개 페이지, 3번은 연구 접근 방법, 4qjs는 비전, 5–8번은 네 연구분야에 사용한다. 원본은 AI_generated_images에 유지하고 빌드에서 반응형 WebP를 만든다. 자료 사진·구성원 사진·논문 도식은 교체하지 않는다. 이미지 위에 긴 본문을 겹치지 않고 모바일에서도 핵심 피사체가 남는 구도를 확인한다.

## 4단계 구성원과 연구실적

구성원은 교수 요약과 여섯 분류를 유지한다. 긴 소개와 실적은 명확한 펼침 버튼 아래에서 읽는다. 항목이 길어도 다른 카드와 겹치지 않도록 상세 영역의 폭과 여백을 정한다. 이름 별칭을 통한 자동 실적 연결은 기존 로직과 대조한다.

연구실적은 최신 연도부터 연도별로 묶고 제목·저자·출처·관련 링크를 일관된 순서로 표시한다. 상단에 검색창과 연도 선택, 전체/저널/국제학회/국내학회/특허 버튼을 둔다. 연구주제는 접을 수 있는 보조 필터로 제공한다. 검색 결과에서 비어 있는 연도는 숨기고 전체/표시 건수와 빈 결과 안내를 갱신한다. 필터 상태는 URL에 남겨 새로고침·공유·뒤로 가기가 가능하게 한다. 링크가 없는 기록에 가짜 Paper 버튼을 만들지 않는다.

## 5단계 과제와 강의 및 지원

과제는 기간, 지원기관, 과제명, 설명·성과의 위계를 구분하고 18건을 그대로 표시한다. 강의는 최신 학기를 강조하되 과거 12학기를 모두 읽을 수 있게 한다. 일정·장소·자료는 원본에 있는 항목만 표시한다. 지원 페이지는 제출서류와 기존 GKS·지원 프로그램의 기준일을 보존하고 이메일로 연결한다. 작동하지 않는 템플릿 문의 폼은 넣지 않는다.

## 6단계 블로그와 앨범

블로그 목록은 날짜·제목·부제·있는 경우 표지로 구성한다. 표지가 없는 글도 균형 있는 텍스트 카드로 표시한다. 본문 표·목록·인용·HTML·그림·저자 소개를 보존한다. h2/h3 목차를 계층으로 표현하고 앵커가 고정 헤더 뒤에 가리지 않게 한다. 확대 모달에는 원본 보기·닫기·설명과 키보드 포커스 처리를 제공한다.

앨범은 원래 18개 행사와 76개 사진을 그대로 유지하고 연도/행사 탐색을 돕는다. 갤러리 장식 때문에 사진을 자르거나 원본 링크를 잃지 않게 한다. JavaScript가 없을 때도 이미지 링크로 원본을 열 수 있어야 한다.

## 7단계 배포 경로와 검증

SITE_URL과 BASE_PATH를 공통 설정으로 두고 내부 URL, Markdown·HTML 이미지, srcset, 언어 전환, 구형 해시 리다이렉트, canonical/alternate/OG, sitemap/robots에 적용한다. GitHub Actions는 포크의 실제 저장소 이름으로 경로를 계산한다. 운영 master/main과 명시적 실행에 게시 단계를 연결하며, 개인 포크의 redesign/story는 원래 브랜치를 보존하는 빌드·검증·결과물 보관에 사용한다. 로컬은 Go Live(5500)와 루트 index.html에서 접근하며, 원본 저장 시 자동 빌드한다.

원본과 새 결과의 데이터 해시·52개 경로·구성원 연결·서지 정보·본문 내용을 비교한다. 루트와 /hongjo.github.io 접두사로 각각 빌드·검사한다. 브라우저에서는 모바일 메뉴, 논문 조합 필터·URL 복원·빈 결과, 이미지 모달, 언어 전환, 긴 제목/표, 키보드, 작은 화면과 큰 화면을 확인한다. 적대적 검토에서 발견한 결함은 수정한 뒤 해당 영역과 영향 범위를 다시 검사한다.

## 2026-10-16 사용자 피드백 반영 설계

- 기본 진입은 영어다. 큰 카피는 한국어 화면에서도 영어를 사용하고, 한영 본문은 모두 Serif 글꼴로 표시한다. Noto Serif KR의 가변 WOFF2와 OFL 라이선스를 로컬에 포함한다.
- 홈은 Intro → Research Areas → Selected Papers·Research Stories → Vision·Approach·인재상 → 소식·단체사진·Contact의 다섯 섹션이다. 큰 메인 이미지와 글자 크기는 유지하고 서브 이미지·본문·간격은 화면 높이에 맞춰 줄인다. 데스크톱 높이 600/720/768/900px에서 서브 섹션이 한 화면을 넘지 않는지 검사한다. 좁은 화면에서는 내용을 자르지 않는다.
- 섹션 이름을 강조하고 글자 없는 점 다섯 개로 현재 위치와 이동을 제공한다. 키보드 및 보조기기용 이름은 유지한다. 상단에는 Home을 추가한다.
- People은 기본 여섯 열의 작은 카드, 큰 교수 소개, 파트타임·인턴의 좌우 배치다. 상세를 펼치면 읽기 영역을 넓히고 모바일은 두 열과 세로 그룹을 사용한다.
- 유지민 학생의 사진·한영 소개를 추가하고 Siheon Joo의 개인 홈페이지 사진·BK 최우수 논문상 소개·선호 영문 표기를 반영한다. 과거 하이픈 표기는 저자 연결 별칭으로 유지한다.
- 논문 주제·저자 필터는 항상 펼쳐져 있고 검색·연도·분류와 교차 적용한다. 교수님은 별도 항목, 저자 옵션은 재학생 / Alumni / 외부인사로 묶는다. 이름 별칭을 명시적으로 연결하고 URL·언어 전환·초기화에 저자 조건을 포함한다.
- 앨범은 활동 목록과 선택한 앨범의 사진 영역으로 나눈다. 사진 수와 사용 가능한 너비·높이를 측정해 행·열을 자동 결정한다. 모바일 활동 선택은 드롭다운이고, 사진 확대 시 원본과 전체 설명을 표시한다. JavaScript가 없으면 모든 활동·사진·원본 링크를 탐색할 수 있다.
- 실시간 빌드는 임시 디렉터리에서 완성한 뒤 변경된 자산과 HTML을 순서대로 교체한다. 빌드 중 기존 미리보기 파일을 지우지 않는다.

적대적 설계 검토: 고정 높이에 의한 본문 잘림, 스크롤 잠금, 작은 카드의 상세 가독성, 활동 선택 후 원본·주소 이력 소실, 이름 연결의 오인 가능성을 검토했다. 본문 자연 높이·모바일 재배치·명시적 별칭·기본 HTML 원본 링크·브라우저 회귀 검사로 보완한다. 판정: **이제 충분히 만들어도 됨**.
