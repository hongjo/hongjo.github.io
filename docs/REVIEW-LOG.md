# 개편 적대적 검토 기록

## 평가 기준

콘텐츠 완전성, 기능 보존, 탐색의 명확성, 본문 가독성, 모바일 가시성, 키보드 접근성, 포크 배포 경로, 유지보수성을 평가한다. P0는 공개 콘텐츠 손실·잘못된 배포, P1은 핵심 기능 불능·본문 잘림·주요 접근성 실패, P2는 국소적 사용성·시각 품질 문제로 분류한다. 설계와 제작물은 별도로 평가한다.

## 설계 검토 1

판정: 보완 후 재검토.

- P1: 원래 메뉴와 언어 전환을 Story의 한 페이지 구조에 넣으면 좁은 화면에서 과밀하다. 수정: 헤더와 모바일 메뉴를 별도 공통 컴포넌트로 설계하고 실제 글자 폭을 기준으로 전환한다.
- P1: 홈 중심 구현만으로 about/news/faculty와 30개 게시글 경로가 누락될 수 있다. 수정: 원본 52개 경로를 완료 기준으로 고정한다.
- P1: 개인 홈페이지의 Selected를 가져오거나 홈의 대표 연구까지 지울 수 있다. 수정: 논문 목록의 Selected만 제외하고 원래 홈 대표 연구·링크는 보존한다.
- P2: 템플릿의 가벼운 글꼴과 중앙 정렬을 긴 본문에 적용하면 읽기 어렵다. 수정: 본문 굵기·행간·폭·왼쪽 정렬과 한국어 줄바꿈을 별도 규정한다.

## 설계 검토 2

판정: 보완 후 재검토.

- P1: 포크가 하위 경로에 배포되면 이미지·언어 전환·Markdown 링크가 깨진다. 수정: 빌드 전체에 BASE_PATH와 SITE_URL을 적용하고 두 경로 모드를 검사한다.
- P1: 반응형 이미지가 원본 이미지를 대체하면 확대 화질과 캡션이 손실될 수 있다. 수정: 원본 경로와 설명을 유지하고 링크 기반 점진적 향상을 사용한다.
- P1: 128개 실적을 분류에서 연도로 재배치할 때 특허나 연결 정보가 누락될 수 있다. 수정: 모든 레코드를 공통 목록으로 정규화하되 원본 필드를 보존하고 분류별 수를 대조한다.
- P2: 긴 표와 구성원 상세 실적의 길이가 모바일에서 카드 폭을 넘길 수 있다. 수정: 표는 자체 스크롤, 상세는 가변 높이와 안전한 단어 줄바꿈을 적용한다.

## 설계 검토 3

판정: **이제 충분히 만들어도 됨**.

- 원본 데이터·게시글 파일을 수정하지 않는 구조와 해시 비교를 완료 기준에 포함했다.
- 자바스크립트 비활성 상태에서도 본문·원본 이미지 링크·메뉴가 접근 가능하게 한다.
- 검색 조건 URL 보존, 빈 결과, 결과 수, 초기화, 모달 포커스 복귀와 모션 감소를 명시했다.
- 선택 기능 추가, 가짜 문의 폼, 확인되지 않은 연구 성과·배지·통계는 범위에서 배제했다.
- 설계의 P0/P1 미해결 0건. 제작물 평가는 빌드·콘텐츠·기능·실제 화면 증거를 바탕으로 별도 기록한다.

## 제작물 검토

### 1차 정적 검토

판정: 수정 후 재검사.

- P1: 공통 URL 변환이 본문 외의 canonical과 alternate에도 적용되어 절대 URL이 상대 URL로 바뀌었다. 52개 페이지의 메타데이터 검사에서 검출했다. 수정: 본문과 원본 푸터 콘텐츠만 변환하고 빌드가 생성한 메타데이터는 절대 URL을 유지한다.
- P2: 구형 홈 앵커와 연구실적 분류 앵커도 외부에서 공유되었을 수 있다. 수정: 기존 비전·인재상 앵커와 논문 분류 앵커를 새 화면에 연결한다.

### 2차 브라우저 및 화면 검토

첫 실행: 106건 중 99건 통과, 7건 실패. 판정: 수정 후 재검사.

- P1: Story의 원래 이미지 배경 처리용 CSS가 히어로의 의미 있는 img를 숨겼다. 전체 모바일 캡처에서 발견했다. 수정: 사진을 명시적으로 표시하고 네 가지 화면 폭에서 사진의 가시성과 크기를 검사한다.
- P1: Story의 button 색상 important 규칙으로 선택된 필터의 글자가 검게 남았다. 한영 접근성 검사에서 대비 실패를 검출했다. 수정: 선택 상태의 글자·건수 색상을 흰색으로 고정한다.
- P2: 전체 소식 페이지가 h1 다음 h3를 사용했다. 수정: 전체 목록에서는 h2, 홈의 소식 영역에서는 h3를 사용한다.
- P2: 교수 사진의 전체 풍경을 축소하면 인물이 작았다. 수정: 원본 사진의 얼굴 위치를 기준으로 세로 비율을 적용한다.
- 검사 자체 오류 3건: 검색 영역과 입력란의 접근 가능한 이름이 같아 테스트 선택자가 모호했다. searchbox 역할로 구분한다. 사진 모달의 상대 URL과 동일 파일의 절대 URL을 잘못 다르게 비교한 검사를 실제 해석된 URL 비교로 바꾼다.

### 3차 확대 검토

수정 후 기본 106건은 모두 통과했다. 모바일 메뉴 펼침·선택한 필터·구성원 상세·이미지 모달과 긴 본문의 표 검사를 추가한 109건 중 107건이 통과했다.

- P2: 여러 스크롤 표 영역이 같은 접근 가능한 이름을 사용해 스크린 리더의 랜드마크 구분이 어려웠다. 수정: 본문 안에서 표마다 고유 번호를 붙인다.
- P1: 모든 콘텐츠 해시와 고정 건수를 평상시 검사에서 요구하면 정상적인 콘텐츠 추가도 배포를 막는다. 수정: 일반 검사는 현재 데이터와 결과를 대조하고, 이번 이관의 무변경 검사는 check:preservation 명령으로 별도 제공한다.
- 사용자 추가 자료: image_prompts.txt와 AI_generated_images 8장을 확인해 역할별로 배치했다. 원본 208개 외에 사용자 제공 9개 파일도 이관 검사의 해시에 포함했다. 제공 자료는 변경하지 않았다.
- 원본과 새 페이지 본문의 단어 대조에서 소실된 내용은 없었다. 변경 차이는 UI 분류 이름, 장식 번호, 연도별 그룹화로 줄어든 반복 연도 표기였다. 30개 게시글의 전체 텍스트는 브라우저에서 원본 Markdown 렌더링 결과와 일치했다.
- 기존 개인 포크에 master와 add-jimin-yu 브랜치가 있음을 확인했다. 두 브랜치를 변경하지 않고 새 redesign/story 브랜치에서 빌드·검증 결과를 보관한다. 현재 미리보기는 사용자가 지정한 로컬 Go Live를 사용한다.

### 4차 이미지 및 상태 일관성 검토

109건 재검사는 모두 통과했다. 이어서 추가 이미지의 실제 캡처와 공유 주소의 경계 조건을 검토했다.

- P1: 연구분야 이미지의 원본 height 속성이 남아 좁고 긴 이미지로 표시되었다. 수정: CSS height를 auto로 명시하고 화면 폭별 종횡비 검사를 추가했다.
- P2: 가로로 크게 보이는 히어로·비전 이미지가 960px 변형을 선택해 확대되었다. 수정: 큰 이미지의 sizes를 100vw로 지정하고 히어로의 오른쪽 로봇이 잘리지 않는 위치로 조정했다.
- P2: 모바일에서 히어로와 연구 방법 사진이 연속해 나왔다. 수정: 연구 방법은 설명 뒤에 사진을 표시해 읽는 흐름을 구분했다.
- P2: 구형 #patents 주소에서 초기화한 뒤 새로고침하면 해시가 필터를 다시 켤 수 있었다. 수정: 사용자가 필터를 변경하면 구형 분류 해시를 제거하고 URL의 조건을 현재 상태와 맞춘다. 초기화·새로고침 회귀 검사를 추가했다.

### 최종 로컬 평가

판정: **제작물 완료 기준 충족**. 기록된 P0/P1 미해결 0건. 알려진 P2 항목도 수정했다.

- 52개 한영 경로, 기존 콘텐츠 208개 파일과 추가 이미지·설명 9개 파일의 보존 검사를 통과했다. 텍스트 파일의 플랫폼별 줄바꿈은 정규화하여 비교하고 이미지는 원본 바이트로 비교한다.
- 전체 브라우저 검사 109건이 원본 루트 배포 방식과 개인 포크의 /hongjo.github.io 경로에서 통과했다. 시각 수정 후 홈 관련 7건도 재검사했다.
- 360/390/768/1440px의 레이아웃, 30개 게시글 본문, 논문 조합 필터·이력·공유 주소·언어 전환, 구성원 실적 연결, 메뉴, 이미지 확대·포커스 복귀, 자바스크립트 없는 기본 탐색을 확인했다.
- 한영 주요 페이지, 긴 글의 표와 목차, 모바일의 펼친 메뉴·필터·구성원·이미지 모달에서 axe의 WCAG A/AA 및 best-practice 검사를 통과했다.
- Go Live(5500)의 실제 루트 주소에서 홈 리다이렉트와 논문 페이지 이동, 이미지·스타일·스크립트 요청을 확인했다. HTTP 오류 0건. 루트 index.html과 자동 빌드를 제공한다.
- 화면 캡처는 docs/previews, 자동 검사 요약은 docs/validation-results.json에 보관한다. 화면 직접 제어는 사용자의 요청에 따라 중단했다.
- npm 운영 의존성 검사에서 알려진 취약점 0건. 원래 sharp의 취약점이 수정된 패치 버전으로 갱신했다.

검증 환경은 Windows Chrome의 데스크톱 및 모바일 크기 모사다. 실제 iOS/Safari·Firefox 기기 검증은 수행하지 않았다. GitHub Actions는 Linux Chromium에서도 같은 검사를 실행한다. redesign/story의 자동 실행은 빌드·검증·결과물 보관까지이며, 외부 게시 설정은 변경하지 않았다.

- 원격 검증: 첫 GitHub Actions 실행에서 Linux 빌드·콘텐츠 검사·브라우저 검사가 모두 통과했다. 이후 Pages 설정이 없는 포크에서 게시 구성 단계가 실패했다. 수정: Go Live로 확인하는 개발 브랜치의 자동 실행에서 게시 단계를 제외하고, 검증과 결과물 보관만 실행하도록 조정했다.

## 사용자 피드백에 따른 후속 검토

- 홈을 다섯 섹션으로 묶었다. 메인 크기는 유지하고 서브 이미지·간격·폰트를 조정했다. 영어·한국어 모두 화면 높이 600/720/768/900px의 실제 요소 높이로 넘침을 검증한다. 짧은 데스크톱에서는 뉴스의 제목·날짜를 우선 표시하고 전체 소식 링크에서 본문을 제공한다.
- 글자 없는 위치 내비게이션은 다섯 점으로 줄이고 접근 가능한 이름·현재 위치·키보드 이동을 유지했다. 상단 Home 링크와 내부 앵커를 검사한다.
- People의 기본 목록·교수 강조·파트타임/인턴 배치·모바일 펼침을 검토했다. 유지민 학생을 추가하고, Siheon Joo의 사진·수상 소개·영문 표기를 수정했다. 기존 데이터 중 사용자 요청으로 바뀐 세 파일의 최초/수정 해시는 content-amendments.json에 기록한다.
- 앨범의 최종 요구는 활동 선택과 한 화면 자동 배치다. 가장 많은 14장 앨범을 1440/768/390px에서 모두 노출하는지, 사진 확대·포커스 복귀·뒤로가기·새로고침을 검증한다. 모바일 설명은 확대 창에서 읽을 수 있게 하고 썸네일 공간을 확보했다.
- 상대 이미지 URL과 같은 파일의 절대 URL을 다르게 비교하던 새 테스트를 해석된 URL 비교로 수정했다. 한국어 필터 이름의 띄어쓰기를 잘못 가정한 테스트도 실제 접근 가능한 이름으로 수정했다.
- 모바일 압축 과정에서 장식 태그를 접은 뒤 예전 테스트가 숨겨진 태그로 스크롤하려 했다. 실제 연구 설명과 Contact의 도달 가능성을 검사하도록 갱신했다. 화면 높이 600px에서 2px 남던 넘침은 간격을 줄여 수정했다.
- 빌드 도중 출력 디렉터리를 지워 순간적으로 파일이 없어지는 문제를 검출했다. 임시 디렉터리 빌드·자산 우선 배치·파일 단위 교체로 바꿨다. ESM 별칭의 구문 오류를 node --check로 검출·수정했고, 이전 완성 미리보기는 유지됐다.
- 한영 Serif는 로컬 Noto Serif KR을 사용한다. Vision 오른쪽 이미지는 사용자 요청으로 한 장만 남겼다. 원본 추가 이미지 파일은 모두 보관한다.

후속 전체 검사: **119건 통과**. 최종 Home 링크·Vision 이미지 수정은 해당 기능·화면·접근성 검사로 다시 확인하고 원격 CI에서도 전체 검사를 실행한다.

마지막 시각 조정: Vision & Approach를 위쪽에 정렬하고 사진을 1440×900 화면에서 약 585×270px로 키웠다. 짧은 창에서는 높이를 줄여 섹션을 유지한다. 홈 배치·섹션 이동·접근성 관련 8건 재검사를 통과했다. 앞선 Home 메뉴 관련 33건도 통과했다.
